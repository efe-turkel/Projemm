# Efe | Kişisel Portfolyo & İnteraktif CV Web Sitesi 🚀

Modern web teknolojileri, dinamik parçacık fiziği (Canvas), pürüzsüz kaydırma animasyonları ve interaktif CV modülü ile hazırlanmış kişisel web sitesi ve portfolyo projesi.

## ✨ Öne Çıkan Özellikler
- **🌌 İnteraktif Parçacık Ağı (HTML5 Canvas):** Fare hareketlerine duyarlı parçacık fiziği ve aurora ambiyans ışıkları.
- **📱 Sosyal Medya Entegrasyonu:** Instagram, GitHub, LinkedIn ve doğrudan E-posta bağlantıları.
- **📄 İnteraktif CV & PDF İndirme:** Web üzerinde interaktif incelenebilen veya doğrudan tarayıcıdan A4 baskı formatında PDF olarak kaydedilebilen özgeçmiş.
- **🛠️ Yetenekler & Projeler Vitrini:** Canlı filtreleme, interaktif detay pencereleri ve önizlemeler.
- **⚡ Modern Animasyonlar & Ses Efektleri:** 3D kart eğilme (tilt) efekti, daktilo başlık, scroll reveal ve Web Audio API tabanlı fütüristik ses efektleri.
- **🌓 Tema Desteği:** Tek tıkla karanlık ve aydınlık tema geçişi.

## 🛠️ Kullanılan Teknolojiler
- HTML5 (Semantik & SEO Uyumlu)
- Modern CSS3 (Glassmorphism, CSS Değişkenleri, Flexbox, CSS Grid, Keyframes, Print Media)
- Vanilla JavaScript ES6+ (Canvas API, Web Audio API, IntersectionObserver)
- FontAwesome 6 Icons & Google Fonts (Plus Jakarta Sans, Space Grotesk)

## 💻 Yerel Olarak Çalıştırma
Projeyi bilgisayarınızda çalıştırmak için:
1. `index.html` dosyasını herhangi bir tarayıcıda doğrudan çift tıklayarak açabilirsiniz.
2. Veya bir yerel sunucu ile:
   ```bash
   python3 -m http.server 8080
   ```
   Ardından tarayıcınızdan `http://localhost:8080` adresine gidin.
